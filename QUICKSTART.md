# Sravani V - Premium Portfolio Website

A modern, responsive portfolio website built with React (Vite), Tailwind CSS, and Framer Motion showcasing AI engineering expertise, technical mentoring, and full-stack development skills.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## Deployment

### GitHub Pages
```bash
npm run build
git add dist -f
git commit -m "Deploy"
git push
```

### Vercel
1. Connect GitHub repository
2. Vercel auto-detects Vite config
3. Deploy on push

### Netlify
1. Connect GitHub repository
2. Build: `npm run build`
3. Publish: `dist`

## Customization

- Edit content in `src/data/portfolio.js`
- Modify colors in `tailwind.config.js`
- Add/remove sections in `App.jsx`
